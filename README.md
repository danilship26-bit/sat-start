# SAT Start Math

**[Открыть приложение / Open the app](https://sat-start-math-2026.arcane-field-4854.chatgpt.site/)** · [GitHub Pages mirror](https://danilship26-bit.github.io/sat-start-math/)

An independent, multilingual SAT Math learning app. It starts with arithmetic foundations, then covers Algebra, Advanced Math, Problem-Solving and Data Analysis, and Geometry and Trigonometry. Exam-style questions stay in English; explanations and interface text are available in Russian, English, Spanish, and Arabic.

## What is included

- 29 lessons and 138 original Math questions, including 46 numeric or fraction responses.
- 30 short checks of English wording used in Math questions. This is **not** an SAT Reading and Writing course.
- Fresh 22-question modules and four 44-question, 70-minute practice forms: mixed, numeric-focused, wording-focused, and weak-topic review.
- Local progress dashboard for lesson mastery, timed practice and wording comprehension.
- Optional entry of **official Bluebook** Math and Reading and Writing scores. The app compares the combined official practice score with published university score ranges. It does not calculate an official SAT score or an admission probability.
- Optional synthesized interface sounds with a mute button.

## Run locally

Open `dist/index.html` in a browser, or serve `dist/` with a static HTTP server. No build step or account is required. Progress is stored only in the browser's local storage.

## Sources and limits

The curriculum follows the [College Board Math overview](https://satsuite.collegeboard.org/sat/whats-on-the-test/math/overview) and [Math specification](https://satsuite.collegeboard.org/k12-educators/about/alignment/math). All practice questions in this repository are original. The digital SAT has an adaptive second module, which these practice forms do not reproduce. For an official practice score, use [Bluebook](https://satsuite.collegeboard.org/practice/practice-tests/bluebook).

University examples use their own current admissions publications: [Purdue](https://admissions.purdue.edu/become-student/class-profile/), [Georgia](https://admissions.uga.edu/apply/first-year-applicants/admissions-stats/), [Florida](https://admissions.ufl.edu/freshman-student-profile), [Illinois](https://www.admissions.illinois.edu/class-profile/), and [Northeastern](https://admissions.northeastern.edu/application-information/). These describe historical admitted-student scores, not 2027 admission decisions. Applicants must check current rules, English proficiency requirements, grades, financial aid, and deadlines directly with each university.
